# 基础机制：先弄清资源，再比较选择

结论类别：基础规则以当前快照为依据；以下判断方法是本项目策略综合，不是专家背书。版本基线 v0.111.0。数字示例均为教学假设，不是卡牌永久数值。来源：sources.md 的 G1、G2、P1。

## 需要读取

长期状态用 `run`：生命、金币、章节、进阶、主牌组、遗物、药水；战斗用 `combat`：回合、行动方、能量、格挡、Powers、手牌、牌堆、意图、就绪状态及选择。`null` 表示尚未提供/不适用，不能当 0；过渡状态不做算术结论。稳定身份用 ID，中文名称用于显示。

## 回合与资源

玩家回合可以支付资源使用合法牌/药水；结束回合会触发手牌、状态、遗物和敌人行动，具体顺序以文本为准。行动方是玩家不代表动画结束，只有候选与就绪状态确认可操作。能量通常是本回合预算，不能默认剩余能量跨回合保存；遗物或状态可能改变这一点。星能等独立机制即使战士跨角色获得，也须按快照核算，不能因角色是战士忽略。

格挡通常抵消攻击伤害，不是生命回复，也不必然抵消“失去生命”。格挡通常不跨回合保留，有保留/转化机制时例外。生命既是生存边界也是可投入资源；投入生命换取更快结束战斗可能减少整场损血，但低血时不能只想终局成长。最大生命、当前生命、治疗与格挡分开比较，不能把未来尚未获得的治疗先加到当前生命。

**例：** 来袭 11，当前格挡 11，纯格挡牌增加 5，则本回合即时减伤为 0。若该牌还能过牌、触发消耗收益或保留格挡，才有其他价值。不能据此说所有额外格挡都无用。

## 手牌、抽弃消耗、洗牌

主牌组是局外构筑，不等于战斗当前可抽集合。抽牌从抽牌堆获得卡；弃牌在未来洗牌后可能回来；消耗通常在本场战斗离开循环，并非永久从主牌组删除。能力牌打出后的去向及复制生成牌依文本判断。保留、虚无、固有、消耗、不可打出都有具体触发条件；枚举字段与文本同时检查，缺失不能凭名字补。

抽牌堆成员公开不代表顺序公开。不把数组排列当下一张抽牌顺序。抽牌堆空时可能洗入弃牌，具体抽牌结果必须刷新看到才规划；手牌上限会影响过牌收益。将弱牌消耗可改善后续循环，但消耗掉唯一防御/终结手段会让长战失去解法。

**例：** 抽牌效果 2，但能量已用尽：若可能抽到零费牌、触发其他效果或为保留做准备仍可有价值；若没有这些作用且要付生命，就不能把“抽两张”无条件当收益。

## 费用、目标与显示数值

`base_energy_cost` 是基础值，`energy_cost` 是当前显示费用，X 费另看 `costs_x`；星能费用独立。X 不是固定 0，也不能用负数当优惠。动态费用、临时免费、升级、附魔、异变可能同时存在；每次操作后重读。`playable` 是规则/资源判断，不覆盖选择弹窗或动画限制，实际提交以 actions 为准。

单体/群体/随机攻击不能互换。有效伤害可能是牌面值，未必包含特定敌人的易伤、无敌、伤害上限或反伤。若存在目标预览以预览为准；没有时写明假设，不能声称“精确斩杀”。多段每段可能分别取整、触发力量、格挡和反伤，不能先合并再套全部规则。

## 状态、升级与附魔

力量、虚弱、易伤、脆弱等作用的主体不同：敌人易伤与玩家易伤方向相反；状态层数也不都等于持续回合。优先读稳定 Power ID、层数和说明，不凭颜色推断。升级改变卡的能力/费用且通常是长期变化；附魔、锁链等附着效果有各自期限和触发，不能把它们都归为“升级”。同名牌要按实例 ID 分开。

**例：** 两张同名攻击只有一张被附魔，应选对应实例；确认后核对该实例的附魔，不靠总牌数判断成功。临时选择中的“选中”也不是“已确认”，达到数量后可能还要单独确认。

## 从一回合到整局

赢眼前战斗 → 比较奖励与跳过 → 检查构筑缺口 → 规划到下一恢复点/关键遭遇的路径 → 用商店、事件、篝火补齐 → 准备 Boss。金币不用固定换算成生命，卡牌多不一定强，精英多不一定好。每个选择问：它解决哪一段路的什么问题，代价是什么，失去的替代机会是什么？
